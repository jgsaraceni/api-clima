API de clima

Esta API retorna a temperatura atual de uma cidade informada pelo usuário.

Como usar

Use a rota:

/temperatura-cidade?nome_cidade=Curitiba

Exemplo completo:

http://127.0.0.1:1234/temperatura-cidade?nome_cidade=Curitiba

A resposta será a temperatura atual em graus Celsius, por exemplo: 

22.1

Exemplo prático

Se você quiser consultar a temperatura de São Paulo, faça a seguinte chamada: 

http://127.0.0.1:1234/temperatura-cidade?nome_cidade=Sao%20Paulo

Teste interativo

Para testar a API em uma interface mais amigável, acesse o /docs. Lá você pode enviar requisições diretamente pela documentação interativa do FastAPI.
